# wikicollabs.github.io

Source of the Wikicollabs website, published at https://wikicollabs.org.

The site is plain HTML and one stylesheet. It has no build step and uses no
JavaScript.

## Preview

Run this from the repository root:

    python3 -m http.server 8000

Then open http://localhost:8000. Stop the server with Ctrl+C.
